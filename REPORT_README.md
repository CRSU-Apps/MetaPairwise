# MetaPairwise Reproducible Report
To re-run this analysis:
1. Open the `*.Rmd` file in this directory in RStudio and click "Knit"
2. Alternatively, set the working directory for `R` as this directory using `setwd(<DIRECTORY_PATH>)`, and run `rmarkdown::render("<REPORT_NAME>.Rmd")`

The `R` directory contains the functions used by the report, and must be kept alongside the `*.Rmd` file.
